Passoid — AI-Powered Gender Perception Analyzer
Passoid is an advanced experimental tool that analyzes facial photographs and determines the perceived gender presentation ratio using a multi-factor computer vision algorithm.

🌈 What is Passoid?
Passoid is designed to explore the concept of "passing" — how an individual's appearance aligns with societal gender perception. Using sophisticated image analysis techniques, it provides insights into the masculine and feminine traits detected in a photograph.

Key Features
Multi-factor analysis: Examines color balance, texture patterns, contrast levels, and brightness distribution

Pass-index scoring: Measures confidence in gender perception alignment

Real-time visualization: Interactive progress bars and ratio indicators

Trans-inclusive design: Interface themed with the transgender pride flag colors

Privacy-first: All processing happens locally in your browser — no images are uploaded to any server

⚙️ How It Works
The analysis algorithm evaluates multiple visual dimensions:

Factor	Weight	Description
Color balance	40%	Warm/cool color temperature analysis (pink/blue spectrum)
Texture patterns	25%	Smoothness vs. sharpness of facial features
Contrast levels	20%	High contrast often associated with masculine coding
Brightness distribution	15%	Adjusts confidence in extreme lighting conditions
Pass-Index Calculation
The Pass-Index represents the algorithm's confidence in its analysis:

80-100%: High passing potential — strong alignment with perceived gender presentation

60-79%: Good prospects — moderate alignment

40-59%: Neutral profile — balanced masculine/feminine traits

Below 40%: Requires detailed analysis — mixed signals detected

The interface is designed with the transgender flag colors to promote inclusivity and visibility:

Light Blue (#5bcefa): Traditional masculine coding

Light Pink (#f5a9b8): Traditional feminine coding

White: Neutral/transitional space

This design choice reflects the tool's purpose of exploring gender presentation beyond binary constraints.

⚠️ Important Disclaimer
Passoid is an experimental educational tool, not a diagnostic instrument.

The analysis is based on visual patterns and does not reflect a person's actual gender identity

Results should be taken with humor and curiosity, not as definitive assessments

Gender is a complex social construct that cannot be determined by algorithms alone

The tool uses simplified heuristics designed for demonstration purposes

🔒 Privacy Statement

No image storage: Photos are never transmitted or stored

Client-side only: The algorithm runs entirely in JavaScript on your device
